# 例外対応アプリ

例外リストを取り込み、ルールで自動判定 → 期間を選んで精査 → 判定・メモ・精査済をアプリ内に保存するWebアプリです。

## 使い方
1. 「取込」タブでサンプル、またはファイル（xlsx / csv）を読み込む
   - 照合データ：勤怠入力・CTK・早退履歴・VTO（日付＋ログインIDの列があればOK）
   - 例外リスト：日付・ログインID・例外種別は必須。氏名・部署・派遣会社・シフト・打刻は任意
2. 「精査」タブで期間を選び、判定（対応不要／部署共有／部署確認中／対応済）とメモを入力し、精査済にチェック
3. 入力内容は自動で保存されます

## 判定ルール
- 早退：勤怠入力・CTK・早退履歴・VTOのどれかに記録あり → 対応不要／なし → 部署共有
- 遅刻：勤怠入力・CTKに記録あり → 対応不要／なし → 部署共有
- 早出・残業：しきい値（初期60分）以上 → 部署共有／未満 → 対応不要
- 打刻漏れ・その他 → 部署共有
- 部署確認中：部署共有の行が翌日も部署の対応待ちのとき（一括ボタンあり）

## データの扱い
- ファイルはブラウザ内だけで読み込み、外部に送信しません
- 保存先はその端末のブラウザ（localStorage）。端末を移るときは「設定 → バックアップ」を使います
- このリポジトリは公開なので、実データのファイルはコミットしないでください
