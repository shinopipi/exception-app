サンプルデータ

動作確認用の架空データを入れます（直近14日分）。

ファイル取込（xlsx / csv）

ファイルはブラウザの中だけで読み込み、外部には送信しません。

どの順番で入れても、未精査の例外は自動で判定し直されます。

取込済みデータ

判定ルール

  • 早退：勤怠入力・CTK・早退履歴・VTOのどれかに記録あり → 対応不要／どれにもない → 部署共有
  • 遅刻：勤怠入力・CTKのどれかに記録あり → 対応不要／ない → 部署共有
  • 早出・残業：しきい値以上 → 部署共有（現場確認）／未満 → 対応不要
  • 打刻漏れ・その他 → 部署共有
  • 部署確認中：部署共有にした翌日以降も「部署共有」のままの行は、自動で部署確認中に切り替え（アプリを開いたとき・取込時・開いたまま日付が変わったとき）

保存データ

データはこの端末のこのブラウザに保存されます。別の端末に移すときや念のための控えは、バックアップを使ってください。
